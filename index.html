Fundamentação de Infraestrutura

O que é o AWS S3 (Simple Storage Service)?

Armazenamento em Objeto

Diferente de sistemas de arquivos tradicionais, salva arquivos como objetos contendo dados, metadados e chave única de acesso.

Organização via Buckets

Durabilidade dos Dados

Projetado para 99,999999999% (11 noves) de durabilidade, replicando arquivos em múltiplas Zonas de Disponibilidade (AZs).

Resiliência Empresarial

Gatilhos de Eventos

Capacidade nativa de emitir notificações instantâneas (ex: s3:ObjectCreated:*) sempre que um novo arquivo é enviado.

Event-Driven Trigger

No nosso projeto: O S3 atua em duas frentes: como bucket de upload original recebendo fotos enviadas pelo backend Java e servindo as miniaturas finais.

Computação Sem Servidor

O que é o AWS Lambda (FaaS)?

1

Zero Administração de Servidores

Não há necessidade de provisionar, atualizar ou manter sistemas operacionais, instâncias EC2 ou contêineres manuais.

2

Execução Sob Demanda (Event-Driven)

O código permanece inativo (sem custo) até que um evento específico no S3 o invoque para executar a tarefa.

3

Escala Automática Milissegunda

Se 1 ou 10.000 imagens forem enviadas simultaneamente, a AWS instancia cópias paralelas da função automaticamente.

CICLO DE VIDA LAMBDA MILISSEGUNDOS
1. Evento s3:ObjectCreated
2. Spin-up de container limpo (Cold start quando fora do warm start)
3. Redimensionamento Imagem
4. Salvamento ou Descarte após um período ocioso
Pagamento por milissegundo: Só paga enquanto a função está rodando!
Por Que Escolher Essa Arquitetura?

Vantagens Competitivas do Par S3 + Lambda

Custo Zero Ocioso

Em servidores normais você paga 24 horas por dia. No Lambda você só paga os instantes exatos de processamento da foto.

Desacoplamento Total

A API Spring Boot não fica presa processando bytes pesados de imagem. Ela apenas autoriza e registra a operação.

Isolamento de Falhas

Se uma imagem corrompida travar o Lambda, apenas aquele evento falha. Toda a aplicação Spring Boot continua 100% online.

Escala Infinita

Capacidade automática de lidar com explosões de tráfego (ex: Black Friday) sem necessidade de reconfiguração de infraestrutura.

Ferramenta alternativa tradicional (Monólito / Worker Fixo): Consumo Alto de RAM, Risco de OOM (Out Of Memory), Servidor Ocioso Pago

Código e Algoritmo Real

Como Funciona a Função Lambda Python?

1. Validação & Prevenção de Loop

Verifica eventos ObjectCreated: e garante que o arquivo venha do diretório imagens-originais/, evitando recursão infinita no imagens-processadas/.

2. Processamento em Memória (BytesIO)

Baixa o arquivo do S3 via boto3 e carrega a imagem em RAM com Image.open(io.BytesIO(file_content)) sem gravações em disco local.

3. Redimensionamento Proporcional

Aplica image.thumbnail((800, 800)) do Pillow (PIL) mantendo a proporção original do arquivo e otimizando com optimize=True.

4. Upload para imagens-processadas/

Salva o novo arquivo reduzido na chave imagens-processadas/{nome}_reduzida.{ext} preservando o ContentType original.

lambda_function.py Python 3.x + Pillow 
import boto3, io, os, urllib.parse
from PIL import Image

s3 = boto3.client('s3')
TAMANHO_MAXIMO = (800, 800)

def lambda_handler(event, context):
    event_name = event['Records'][0]['eventName']
    if not event_name.startswith('ObjectCreated:'):
        return {"status": "ignorado"}

    bucket = event['Records'][0]['s3']['bucket']['name']
    key = urllib.parse.unquote_plus(event['Records'][0]['s3']['object']['key'])

    # Prevenção de Loop Infinito
    if not key.startswith('imagens-originais/'):
        return {"status": "ignorado"}

    # Download e leitura em memória com PIL
    res = s3.get_object(Bucket=bucket, Key=key)
    image = Image.open(io.BytesIO(res['Body'].read()))

    # Redimensionamento proporcional (800x800)
    image.thumbnail(TAMANHO_MAXIMO)
    buffer = io.BytesIO()
    image.save(buffer, format=image.format or 'JPEG', optimize=True)
    buffer.seek(0)

    # Upload para imagens-processadas/
    novo_nome = f"{nome_base}_reduzida{ext}"
    nova_key = f"imagens-processadas/{novo_nome}"
    s3.put_object(Bucket=bucket, Key=nova_key, Body=buffer)
    return {"status": "sucesso"}
